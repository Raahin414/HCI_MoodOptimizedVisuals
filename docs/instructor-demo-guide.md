# Instructor demonstration — approximately 6–8 minutes

Start from `C:\Dev\moodspace-hci`, run `npm run dev`, and open `http://127.0.0.1:5173`. Use rehearsal mode throughout the demonstration. Read the local administrator password from the ignored `.env`; do not project or distribute it. No password, database or actual participant records are included in the downloadable source.

1. **Originality and parity (1 minute).** Open `/gallery`. Show U01 spotlight, U02 status board, U03 calendar, U04 progress drill-down, U05 subjects, U06 deterministic matrix, U07 guided rules, U08 editorial digest. Open any task, inspect its due date and mark it complete. The same five courses, 24 tasks and eight milestones are available everywhere. Fixture day is explicitly Nov 18, 2026.
2. **Central adaptive flow (2 minutes).** Open `/adapt` from the overview. Select a preferred UI, keep rehearsal provenance, consent, and report Positive, Neutral or Stressed. Optionally type a short sentence and separately opt in. Without a valid real model, the prediction says rule-based demonstration; show that it may abstain, and keep/correct the report. Proceed. The suggestion evaluates all eight candidates and explains user preference or neutral fallback when support is insufficient. Choose another layout; it renders immediately. Mark a task complete, submit optional satisfaction/effort, reload to show persistence, then use Workspace controls to delete the rehearsal.
3. **Experimental collection (2 minutes).** Open `/study`. Explain consent, three self-reports, two scales, optional text opt-in, all eight previews and independent first preference. Complete the unscored Editorial storyboard practice. Show a persisted four-UI assignment, explicit timed start, a deadline task and a completion task, neutral recording, give-up, and satisfaction/effort ratings. The full session has eight scored trials; avoid claiming its human duration from a quick demo. Show saved code, resume and withdrawal controls. The final gallery choice and end mood remain separate; the after-study workspace uses the latest confirmed mood.
4. **Evidence and fairness (1 minute).** Open `/research` privately. Genuine counts may correctly be zero. Show the 24 cells, mean/median success times with failure counts, missing observations, acceptance/rejection rates, and model readiness. Export JSON or CSV ZIP; default excludes rehearsals/tests. Explicit inclusion retains provenance and marks the manifest. `npm run demo:coverage` produces a separate, visibly synthetic report: 48 automated sessions, 8 synthetic codes per cell, zero genuine records. Do not present those generated trials as a study result.
5. **Honest ML and conclusions (1 minute).** Explain TF-IDF/logistic regression, ≥15 opted-in distinct participants per class, grouped validation, macro-F1, balanced accuracy, confusion matrix and majority baseline. Optional local deployment requires a matching portable JSON artifact and passing evaluation; it never unpickles files or shows uncalibrated confidence. No actual model is active with the current empty dataset. H3 needs a later frozen-policy prospective comparison.
