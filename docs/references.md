# Conceptual inspiration and originality

MoodSpace is an original student-workspace HCI implementation. The supplied master prompt is the requirements source. Only the following five public reference files were consulted on 18 November 2026, for research approach. No reference repository was cloned. No reference code, schema, assets, components, visual design, taxonomy, wording or architecture was imported or adapted.

1. [HCI Project README](https://raw.githubusercontent.com/VoidPsyker/HCI-Project/main/README.md): establishes that the reference is a pilot navigation instrument, describes operational checks and explicitly lists participant-readiness limitations. It is not evidence that an adaptive recommender is already successful.
2. [Short pilot protocol](https://raw.githubusercontent.com/VoidPsyker/HCI-Project/main/docs/short-pilot.md): informed the distinction between a planned duration, an accelerated scripted verification and a measured human rehearsal; it also emphasizes incomplete-record handling and versioned timeouts.
3. [Experimental-plan source](https://raw.githubusercontent.com/VoidPsyker/HCI-Project/main/docs/experimental-plan/experimental-plan.tex): informed the high-level practice of specifying variables, neutral feedback, counterbalancing concerns and prospective model evaluation. Its domain, induction procedure and scheduling design are not used here.
4. [Affect-label separation example](https://raw.githubusercontent.com/VoidPsyker/HCI-Project/main/packages/scoring/src/affect.ts): consulted only to reinforce that an intended condition and a participant's report are conceptually different. MoodSpace uses direct voluntary self-report and has no induction or manipulation-check algorithm.
5. [Participant-group validation example](https://raw.githubusercontent.com/VoidPsyker/HCI-Project/main/packages/analysis/scripts/train_pilot_tree.py): consulted only for the principle of keeping participants separate across training and evaluation. MoodSpace's optional text analysis is independently written TF-IDF/logistic regression, uses opted-in before-study text and enforces three-class participant support.

The reference concerns shopping navigation, six menu structures and induced conditions. MoodSpace concerns academic task completion, eight independently organized workspaces and three naturally observed self-report classes. It has no watch inventory, radial/fractal menu, mood induction, webcam or gaze collection. Attribution acknowledges an idea; it does not imply a copyright license or permission to reuse implementation material. The reference's model evaluation was not audited beyond the allowlisted files and no success or accuracy claim is borrowed from it.

Other implementation dependencies are installed packages with their own licenses retained by the package manager. The academic course/task fixture and visual previews are original fictional demonstration content. They are not participant observations. Refer to `package-lock.json` for exact dependency versions.
