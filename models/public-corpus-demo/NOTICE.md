# GoEmotions-derived external demonstration

Data attribution: Dorottya Demszky, Dana Movshovitz-Attias, Jeongwoo Ko, Alan Cowen, Gaurav Nemade and Sujith Ravi (2020), GoEmotions: A Dataset of Fine-Grained Emotions, ACL 2020. https://aclanthology.org/2020.acl-main.372/

Original data: https://github.com/google-research/google-research/tree/7951440944924ac61b6e2f9a2a3c715834005c40/goemotions

The original publisher states datasets are CC BY 4.0; the accompanying license text applies to this attributed data-derived numeric artifact. Source code in the upstream repository is separately Apache 2.0; no upstream model code is copied.

Changes: strict three-class proxy remapping, removal of duplicate normalized comments, training cap, SHA256 feature hashing, TF-IDF and logistic regression. No raw Reddit comments, IDs, author names, or corpus vocabulary are distributed. The artifact contains only numeric hashed feature weights. No endorsement by the original authors or Google is implied.

This is external_public demonstration evidence, never MoodSpace participant/self-report evidence. Fear/nervousness is not stress. The genuine-study model gate rejects this artifact format.
